# Qdral Computer-Use Scope Boundary

Status: PLANNED SCOPE SUMMARY FOR QDRAL-P18
Date: 2026-10-03

P18 is a governed computer-use successor program. It is not part of SG-000066 runtime authority and does not block the P17 v0.2 distribution path.

Included only through separately activated grains: live isolated browser hosting, governed browser networking, live DOM/AX observation, structured browser actuation, bounded live transfers, browser tool exposure, exact-window capture, structured Windows UIA actuation, governed coordinate fallback, provider-neutral model action adapters, bounded remote computer-use leases, and adversarial/security/privacy/performance qualification.

Not included by inference from UI-TARS: arbitrary JavaScript/CDP, unrestricted shell/script, generic sockets/proxy, personal browser profiles, raw model-to-input, whole-screen/background streaming, credential/security-dialog automation, remote approval/self-grant, silent elevation, silent coordinate fallback, arbitrary file transfer paths, mutation retry after dispatch, or runtime dynamic donor-code fetch.
