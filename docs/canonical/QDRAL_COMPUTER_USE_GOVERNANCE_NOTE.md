# Qdral Computer-Use Governance Note

Status: PLANNED GOVERNANCE NOTE
Date: 2026-10-03

The UI-TARS donor study does not modify the authority of SG-000066. In SG-000066, UI-TARS is evidence input only. Any donor capability that launches/attaches to a browser, loads pages, observes live DOM/AX, captures pixels, actuates browser/desktop input, parses model actions for execution, transfers browser files, or extends remote computer control is classified for successor work and remains unreachable until its own QDRAL-P18 grain is explicitly activated and qualified.

COTRA-P17 remains the provider-distribution/v0.2 sequence and does not depend on implementing QDRAL-P18. QDRAL-P18 is planned after SG-000072 so v0.2 release work is not blocked by computer-use feature expansion.

Historical Cotra evidence remains historical. New planning/runtime identity uses Qdral while existing canonical historical files are not blindly renamed.
