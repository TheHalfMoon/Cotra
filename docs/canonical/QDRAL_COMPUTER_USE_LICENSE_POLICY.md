# Qdral Computer-Use Donor License Policy

Status: PLANNED
Date: 2026-10-03

Permission to use donor source does not replace provenance and redistribution hygiene. Before any UI-TARS-derived file is imported, SG-000073 must record exact source path/revision, file/package license, required notices/attribution, modification notice obligations, relevant transitive dependencies, and Qdral destination. Mixed package licensing must be handled per selected boundary rather than assuming the repository root license covers every package identically.
